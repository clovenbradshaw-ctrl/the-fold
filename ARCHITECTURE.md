# Architecture

The README's [What runs where](README.md#what-runs-where) table covers the
six files a newcomer needs to understand the fold mechanism itself. This
document is the rest of it: all ~200 top-level modules, grouped by what
they're for, so landing on this repo's file listing doesn't read as noise.

Every file listed here carries this same description as its own first
comment line — nothing below is asserted without the source also saying it
about itself. This map is generated by reading those headers, not written
from memory, so it drifts back into accuracy the same way it was built:
re-run `head -1` (or `-3`) on anything that looks stale.

**One thing worth knowing up front:** a chunk of files here are **shims**,
not real modules — see [Migration shims](#migration-shims) at the bottom.
The organs are mid-move into `eoreader7/native/organs/`; a shim just
forwards an old import path so nothing breaks while that finishes.

## The core (see README)

`fold.js`, `source.js`, `holon.js`, `constitution.js`, `app.js`, and every

constitution channel, and the page. Start with the README if you haven't.

## Terminal (sandboxed languages)

`term.js` is the sandboxed terminal itself; `grid.js` is its composition-law
parser; `term-lessons.js` is its tutor. Each language runs in its own
vendored, localhost-served worker (no CDN, P1):

`term-js-worker.mjs`, `term-py-worker.mjs` (pyodide), `term-r-worker.mjs`
(webR), `term-ruby-worker.mjs` (ruby.wasm), `term-php-worker.mjs`
(php-wasm), `term-sql-worker.js` (sql.js).

## Where the essays went

This repo's prose essays and finding/integration notes (2026-09-14) were
archived — byte-identical, with provenance — into
[`eo-compendium`](https://github.com/clovenbradshaw-ctrl/eo-compendium)'s
`lineage/12-the-fold/`, and removed from here. `POLICIES.md`, `CLAUDE.md`,
`NEXT-PASSES.md`, and the rest of the policy/spec set stayed — those are
live operating instructions every session reads, not historical prose.
`eo-historian` is the narrative history built from this lineage's commits
and documents; `eo-compendium` is the document archive; this repo is the
code.
