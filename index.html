Every answer is read back against your own material. What nothing backs is looked up, and when the lookup comes up empty it says so instead of filling the gap. Drop a file anywhere to give it something to stand on.

A build is a skeleton first, then one function at a time — each run in a severed sandbox and witnessed, every repair shown, the model's share of the characters counted. It lands as a fold: an append-only log you ask for changes to, where the file is a projection of the log and every revision keeps the one before it.
